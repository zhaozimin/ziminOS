# 欢迎回家

这里是你的笔记库。

现在它还是空的，但 Dataview、Minimal 主题、配色和 CSS 已经布置好了。跟着下面三步，一分钟就能住进来——开荒完成时，项目、人脉、复盘三套系统会一起长出来。

---

## 三步开荒

**第一步**：Obsidian 打开这个文件夹的时候，会弹出一个窗口问你信不信任。点「信任作者并启用插件」。ziminOS、Dataview 和 Style Settings 会一起启用。

**第二步**：点左下角的齿轮图标，打开设置。在左边那一列往下找，找到 **ziminOS**，点它。

进去以后，顶上有一排标签：**开荒、项目、灵感、复盘、人脉、客户、外观、边栏**。一个标签就是一套系统，各管各的设置，你现在停在第一张「开荒」上。

**第三步**：点「初始化」按钮。

它会问你叫什么名字。填上，回车。不想填就按 Esc 跳过。

屏幕右上角冒出「开荒完成 ✅」，就成了。

这时候会自动打开一个叫「导航」的页面。以后每天，都从它开始。

## 先看一眼最左边那一列

开荒完成后，屏幕最左边那一条竖着的图标栏里，会多出七个 ziminOS 的图标。**鼠标停上去会告诉你它是谁，点一下就直接执行**，不用记快捷键、也不用打字：

| 图标 | 它做什么 |
| --- | --- |
| 一面旗 | 新建项目 |
| 一个灯泡 | 记录灵感 |
| 一本日历 | 打开今天的日记 |
| 一支笔 | 写复盘主题 |
| 一个人带颗心 | 新建人脉 |
| 一份礼物 | 记人情 |
| 一块调色盘 | 打开外观开关 |

这七个是默认摆出来的，判据是「一天里可能按不止一次」。ziminOS 一共有二十二条命令，剩下十五条都在**设置 → ziminOS → 边栏**那一页里，勾一下就出现在这一列，取消勾选就收走。

下面每个动作我都会写「按 `Cmd + P`」那条路——因为二十二条命令都能那么走，而边栏上只摆着你勾过的那几个。两条路通向同一件事，用顺手的那条。

## 日常六个动作

### 一、开一个新项目

按 `Cmd + P`（Windows 是 `Ctrl + P`），输入「新建项目」，回车。

它问你两件事：项目叫什么、你想把它做成什么样。

填完，一个项目文件夹就建好了，里面躺着一张项目总览页。

### 二、写一张卡片

在项目总览页里，连打两个左方括号 `[[`，输入卡片的名字，回车。

现在页面上多了一个蓝色的链接。点它。

一张新卡片就长出来了。它会问你「这张卡片讲什么」，用一句话回答就行。

时间、编号、归属，它自己填，你不用管。

### 三、把项目收起来

项目做完了，按 `Cmd + P`，输入「完成项目」，回车。

整个项目文件夹会自己搬进「已归档」，状态改成已完成。

不想做了，用「放弃项目」。只是先放放，用「暂停项目」。

哪天想捡回来，用「重新开始项目」，它会原样搬回来。

### 四、随手记一条灵感

按 `Cmd + P`（Windows 是 `Ctrl + P`），输入「记录灵感」，回车。

把脑子里刚冒出来的那句话写进去，再回车。它会自动进入 `00-inbox/灵感集.md`，最新一条排在最前面，还会带上今天的日期和时间。灵感集第一行先显示标题，Dataview 从第二行开始展示未完成任务，可以直接勾选；任务组标题会显示这篇灵感集的最后更新时间，下方保留全部历史记录。

想换文件夹、笔记名称、插入位置或记录格式，就到设置 → ziminOS → 灵感那一页改。想真正一键呼出，可以在设置 → 快捷键里搜索「记录灵感」，绑定自己顺手的按键。

## 每天一句话，一年一条主线

### 五、写今天的日记

按 `Cmd + P`，输入「打开今天的日记」，回车。今天那一篇就出来了，没有的话它自己建。

日记只写两样东西：上半截「今天做了什么」一行一件事，写过程；下半截「今日产出」自动列出你今天新建和改动了哪些笔记，不用管。

**傍晚收工前，再按一次 `Cmd + P`，输入「写复盘主题」**，用一句话说清今天主要做了什么。就这一句。

这一句是整套复盘的入口。你只写这一次，剩下的四级全是它的投影：

- 周复盘看七句日主题连起来是什么
- 月复盘看四条周主题连起来是什么
- 一直到年

「打开本周复盘 / 本月 / 本季 / 本年」也都在命令面板里。站在周记上按「写复盘主题」，写的就是周主题——一条命令管五级，它自己认得出你站在哪。

### 六、把人记下来

按 `Cmd + P`，输入「新建人脉」。它问三件事：他叫什么、多久该跟他说句话（密/近/熟/远）、这段关系往哪个方向使劲。

建好之后，**你再也不用打开这份档案去更新它**。日常发生的事只写一处——当天日记，句子里带上 `[[他的名字]]`。三种写法自动分流到他的档案：

| 你在日记里写 | 它落到哪 |
| --- | --- |
| `- 和 [[张三]] 去了新疆，谈定一起投一家网咖` | 他档案的「关键事件」 |
| `- [ ] 出网咖投资方案给 [[张三]]` | 他档案的「待办」 |
| `- [[张三]]｜去｜送了半斤生普｜两清` | 他档案的「人情账本」 |

最后那种也可以用命令「记人情」四步点选，不用手打。

打开 `02-areas/人脉/人脉MOC`，四张表自动长好：谁在名录里、该给谁送东西、这个月谁过生日、谁还欠着谁。**「最近联系」是从日记里算出来的，不用你填**——超过该层节奏的会自己标上 ⚠️，那就是该找他的信号。

### 靠卖东西吃饭的，再加一步

按 `Cmd + P`，输入「初始化客户模块」，跑一次。客户 MOC、模板和目录一次长齐，多出三条命令：「新建客户」「增加付费」「记收款」。

不做生意就别跑它——没跑之前，你的库里不会多出任何一张空表。

## 七个文件夹，各管一摊

| 文件夹 | 放什么 |
| --- | --- |
| `00-inbox` | 收件箱。脑子里冒出来的东西先扔这儿，以后再说。 |
| `01-projects` | 项目。有明确结果、你希望它结束的事。 |
| `02-areas` | 领域。要长期照顾、没有终点的事。比如健康、家人、手艺、人脉。 |
| `03-resources` | 资料。你感兴趣的主题，收藏的、查来的东西。 |
| `04-archives` | 已归档。做完的、放弃的、暂停的，都在这儿躺着。 |
| `05-diary` | 日记与复盘。日、周、月、季、年五层，时间轴住这儿。 |
| `90-system` | 系统。导航页和模板住在这里。平时不用进来。 |

前五个加最后一个回答「这东西属于谁」，`05-diary` 回答「这事什么时候发生」。两种问法不是一回事，所以它单独占一格。

一句话记住顺序：**先收进来，再动起来，长期养着，随手查着，做完收起来，天天记着，工具放一边。**

## 四个小提醒

**关于外观**：笔记库默认使用 Minimal 主题和 ziminOS 配色。你可以在设置 → Style Settings 里改颜色；升级 ziminOS 不会把你改过的配色覆盖掉。

看右下角，有个 🎨 按钮。点开是十二个外观片段的开关——文件夹前面的图标、彩虹引导线、代码块行号、当前行高亮、属性栏自动收起，都在这里，看着不顺眼随手关掉，立刻生效，不用重启。有两个默认是关着的（代码块横向滚动、水平线中间加图标），想试就打开。

这些开关记的是你的选择，升级 ziminOS 不会替你重新打开你关掉的东西。嫌这个按钮碍眼，可以在设置 → ziminOS → 外观那一页把它收起来——最左边那列的调色盘图标和命令面板里的「打开外观开关」照样能打开它，三条路通向同一个面板。

**关于左边那列图标**：想加想减都在设置 → ziminOS → 边栏那一页，二十二条命令列在那儿，每行左边就是它在边栏上的样子。两件事先说在前面：其一，取消勾选后它在「设置 → 外观 → 功能区」和手机端的边栏菜单里要重启 Obsidian 才彻底消失；其二，反过来，你在 Obsidian 自己那个「功能区」里藏掉的图标，回 ziminOS 这边勾上也不会出现——那是 Obsidian 的开关，得回那儿打开。

**关于排版**：你写完一篇笔记、切到别的笔记去，ziminOS 会顺手替你把这一篇整理成标准的 Markdown 写法——汉字和英文、数字之间补一个空格，标题、列表、表格、代码块上下各留一个空行，多余的空行收成一行。**它不会在你正打字的那一篇上动手**，所以不用担心打到一半被打断；想当场整理就按 `Cmd + P`，输入「整理当前笔记格式」。

有一件事它绝对不做：动你的双链。`[[人脉MOC]]` 里面一个空格都不会加，空格只补在方括号外面——链接照样点得动。

九条规则都能单独关掉，路径是设置 → ziminOS → 排版。不喜欢中文里插空格的，就关掉第一条，其余八条照常。

**关于模板**：如果你想手动套模板，需要打开 Obsidian 的「模板」功能。路径是：设置 → 核心插件 → 找到「模板」→ 打开开关。大多数时候它本来就是开的，你可以先不管这条。

**关于图片**：往笔记里贴图片的时候，旁边会自动冒出一个叫「附件」的文件夹，图片都在里面。这是正常的，别删它。
