# src/modules/setup/

> L2 | 父级: ../../CLAUDE.md

开荒模块。它在 V2 从 projects 里独立出来，因为开荒横跨全库骨架并要收齐三个模块的诉求——住在其中任何一个模块下面，都是让物理位置对读者说谎。

## 成员清单

init.ts: 开荒编排，由设置页按钮与 init-vault 命令唯一触发。它只保证两件事属于笔记库本身：PARA 骨架目录，以及「开荒过没有」这个事实。其余产物一律由各功能模块自报 VaultSeed，main 装配后递进来——因此本文件不 import 任何兄弟模块，加一个模块只需在 main 多传一个 seed，这里一行不改。另导出 applySeed 供客户模块的按需开荒复用，让「开荒时长出」与「按需长出」是同一段代码的两个触发点，而不是两份各自演化的实现。

## 模块契约

首次开荒与后续补齐走同一条流程，差别只有三处：空库检查、各模块的 finish、以及 initializedAt 只在首次落笔。那个字段与设置页文案说的都是「首次开荒于」，补齐时重写它等于让面板向学员陈述一件关于他笔记库历史的假事。因此「初始化」按钮永远可点：误删的模板、导航或人脉 MOC，再点一次就补回来，而已有笔记一个字都不动。

VaultSeed 是本模块认识的唯一形态。它有三个字段而不是两个——folders 与 notes 之外还有可选的 finish，因为「开出第一个项目」这类动作只该在首次发生，而它天然属于提出诉求的那个模块，不属于开荒本身。

第七个根文件夹 05-diary 不在 INIT_FOLDERS 里，人脉目录也不在。它们由复盘与人脉模块各自带来：「这个目录存在，是因为那个模块存在」这件事必须在代码里也成立，否则删掉一个模块，库里会留下一个永远空着的目录。
