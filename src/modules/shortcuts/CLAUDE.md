# shortcuts/
> L2 | 父级: ../../CLAUDE.md

右侧正文只显示命令按钮，不画标题或简介。
按钮只调用命令台回调，业务写入仍归原命令。
自定义名称只改变右侧显示，不反写命令身份。
本模块不导入其他业务模块，不创建笔记。

## 成员清单

view.ts: 纯按钮 ItemView 与原命令执行。显示八条常用与四条固定笔记按钮，不重复显示已固定的笔记命令。侧栏菜单和原生页头动作打开配置。按钮右键支持改名与恢复原名。点击恢复主区上下文，文件路径只进悬停提示。注册前判断宿主恢复窗口，事件随视图卸载。
preferences.ts: 按钮组合与自定义名称的唯一写入口。视图和配置弹窗共用保存锁及订阅。提交前保留快照，落盘失败恢复组合与名称，不改左侧边栏配置。
customize.ts: 按需打开的命令检索、固定清单与名称问答。检索同时匹配自定义名、原名和分组；改名复用 TextInputModal，取消不写，空白恢复原名。插件卸载关闭未提交问答，配置弹窗关闭后撤掉订阅。
styles.css: 窄侧栏按钮网格与配置弹窗的滚动清单。正文只留八像素边距与按钮间距。颜色取宿主语义变量，命令图标沿用分组色，构建合并交付。

## 配置边界

quickActionCommands 保存常用组合，与左侧清单独立。
quickActionLabels 按命令 id 保存右侧显示名。
原命令名称、快捷键与回调保持不变。
四条笔记按钮默认显示，可在配置弹窗改名。
没有 Markdown 笔记时，笔记按钮禁用。
默认组合与未知 JSON 验形归 core/shortcutSettings。
