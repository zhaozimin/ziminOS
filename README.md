# ziminOS

> 一句话：一个能自己开荒、管项目、收灵感、读书划线、经营人脉、逐级复盘，而且开箱就好看的 Obsidian 个人知识管理系统。

> **给桌面智能体：** 如果用户已经创建并命名一个文件夹、用你打开该文件夹后要求按照本仓库搭建个人知识管理系统，立即读取并严格执行 [`skill/SKILL.md`](skill/SKILL.md)。当前工作区就是最终 Obsidian 笔记库；不要询问名称或路径，不要创建子目录，不要在当前工作区克隆本仓库，只把 `vault/` 的内部内容直接铺到当前工作区根目录。

---

## 一分钟安装

先创建一个**空文件夹**并取好名字，再用桌面智能体打开这个文件夹。然后把下面整段指令复制给它：

```text
请根据 https://github.com/zhaozimin/ziminOS/blob/main/skill/SKILL.md，在当前工作区原地搭建我的 Obsidian 个人知识管理系统。当前工作区就是我已经创建并命名的最终笔记库：不要询问名称或安装路径，不要创建子级笔记库，不要把源码仓库克隆到当前工作区。请严格执行 SKILL.md 中的安装、验证与清理步骤，完成后告诉我如何用 Obsidian 打开并初始化。
```

安装完成后，直接用 Obsidian 打开**同一个文件夹**。不需要 Node.js，也不需要另行下载插件、主题或字体。

## 三个角色

ziminOS 不是一个插件，是三样东西咬合在一起。

```
   你  ──说一句话──▶  桌面智能体  ──读──▶  skill/SKILL.md
                          │                （施工手册：怎么装、装到哪、什么时候必须停手）
                          │
                          │ 照着装
                          ▼
                      vault/  笔记库成品
                      （学员的「家」：系统配置 + 外观包 + 新手导游）
                          │
                      ├─ ziminos 插件：开荒 · 项目 · 读书 · 灵感 · 中国日历 · 复盘 · 人脉
                      │                排版 · 编辑 · 文件 · 旧版三入口
                          ├─ Dataview：灵感集未完成任务的交互视图
                          ├─ Outliner：列表的快捷键操作与缩进线
                          ├─ Quiet Outline：可搜索、可折叠的大纲面板
                          └─ 外观包：Minimal · Style Settings · 默认配色 · ziminOS CSS
```

**手册**负责把家搭起来，**家**负责收纳，**ziminOS** 负责系统工作流，**Dataview** 负责查询，**Outliner** 与 **Quiet Outline** 负责大纲与列表，**外观包**保持独立运行。它们一起交付；农历换算仅编译进锁版的 MIT 开源库，其他第三方插件与外观资产仍独立交付。

## 管家会干什么

三十五条命令分成十一组，都能按 `Cmd + P` 调用；其中十条默认摆在左侧边栏。中国日历则默认常驻右侧边栏，不需要再占一个左侧按钮。核心工作流是：

| 工作流 | 干什么 |
| --- | --- |
| 开荒 | 建 PARA 六个文件夹、模板、导航页和第一个项目 |
| 项目 | 新建项目/领域、登记卡片，完成/暂停/放弃/重启时整体归档或搬回 |
| 读书 | 从豆瓣自动查书目，合并微信读书、Kindle 与 Apple Books 划线，再把值得拓展的内容摘成卡片 |
| 灵感 | 一个输入框记下一句话，默认置顶进入 `00-inbox/灵感集.md` |
| 中国日历 | 年/季/月独立翻页，显示农历、节气、传统节日、法定休/班；点日/周/月/季/年直达对应记录 |
| 复盘 | 日/周/月/季/年五级复盘；打开日记时补齐缺失主题，已写过则不再打扰 |
| 人脉与客户 | 建人脉、记人情，管客户、付费与收款流水 |
| 排版与外观 | 自动整理 Markdown，一键开关十二个 CSS 外观片段 |
| 文件浏览器 | 每个文件夹右侧显示里面有多少篇笔记（也可以改成数子文件夹）；侧栏一张「最近文件」清单；状态栏显示当前笔记路径，点一下复制 |
| 编辑 | 选中文字直接粘一条网址就变成外链；每篇笔记记住上次的光标位置，重启也还在 |
| 旧版三入口 | 把 Obsidian 1.6 挪进文件浏览器底下的「切换笔记库 / 帮助 / 设置」请回最左边那一列 |

两个自动行为（可在设置里关）：

- **新卡片自动登记**——在项目/领域目录里点出一张空白笔记，它自己把字段补齐。
- **updated 自动维护**——已有 YAML 的笔记改动后，更新时间自己刷新。

「记录灵感」不需要 QuickAdd。灵感集第一行是标题，Dataview 查询从第二行开始：打开笔记时能立即看到并直接勾选全部未完成任务，分组标题会同时显示这篇文件的真实最后更新时间，下方保留完整历史。设置 → ziminOS → 灵感里，可以改文件夹、笔记名称、定位标题、插入位置和单条格式；格式支持 `{{content}}`、`{{date}}`、`{{time}}`、`{{datetime}}`。v0.3.0 已生成的旧灵感集，下次记录灵感时会自动把系统查询移到标题下方，并补上最后更新分组。若想一键呼出，再到设置 → 快捷键给它绑定自己顺手的按键。

## 设计红线

这三条是产品的地基，不是可选项：

1. **人主导**——插件的一切写入都由用户的命令或用户创建的文件触发。没有定时器，没有后台轮询。
2. **脚本驱动**——插件运行时零 AI，本机流程同输入同结果。网络只服务两类机器可核验的外部事实：读书模块查豆瓣书目/取本人微读划线，日历模块校验国务院节假日/调休；日历无定时器，24 小时内读缓存，失败保留最后好数据。
3. **官方 API 优先**——原则上只用 `obsidian` 包公开 API；三处必要缺口（微信扫码登录、CSS 即时开关、旧版那三个入口）已在 [`CLAUDE.md`](CLAUDE.md) 中按边界、降级与删除方式完整备案，每一处都做到「探不到就降级，绝不抛异常」。

AI 参与的地方只有一处：装库那一次，桌面智能体照着 `skill/SKILL.md` 干活。装完它就退场了。

## 给学员：完整安装步骤

你不需要懂命令行。照着四步做：

1. 先创建一个空文件夹，并给它取好名字。这个名字就是你的个人知识管理系统名称。
2. 用桌面智能体打开这个文件夹，让它在这个文件夹中工作。
3. 复制粘贴上方「一分钟安装」里的整段指令。
4. 安装完成后，直接用 Obsidian 打开同一个文件夹。

智能体不会再问名称或安装路径，也不会创建另一层文件夹。它会在工作区外临时读取仓库，只把真正有用的笔记库内容放进当前文件夹；你不会看到 `src`、`docs`、`package.json` 等开发文件，也不需要安装 Node、QuickAdd 或 Linter。Dataview、Minimal、Style Settings、默认配色、CSS 和四款阅读字体都已在仓库中。之后跟着笔记库里的 `README.md` 走三步，一分钟开荒完成。

请使用 Obsidian 1.13.0 或更高版本。

想学得更系统：**https://edu.zhaozimin.com**

## 给开发者：怎么构建

```bash
npm install
npm run build
```

`npm run build` = `tsc --noEmit`（严格模式类型检查）+ esbuild 打包。产物直接落在 `vault/.obsidian/plugins/ziminos/main.js`——**构建即就位**，没有中间同步脚本，也没有 dist 目录。

开发时用 `npm run dev`，watch 模式 + inline sourcemap，改完文件在 Obsidian 里重载插件即可。

产物**刻意提交入库**（不进 `.gitignore`），这样学员拿到仓库就能直接用，不需要装 Node。

代码规约：TypeScript 严格模式、注释中文、单文件 ≤ 800 行、禁 `console.log`（用户可见反馈一律走 `Notice`）、常量统归 `src/core/constants.ts`。每个业务文件带 GEB L3 头部契约。
