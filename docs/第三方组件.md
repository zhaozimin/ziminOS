## 升级所有权边界

| 资产 | 全新安装 | 升级 |
| --- | --- | --- |
| ziminOS `main.js` / `manifest.json` | 写入 | 更新锁定产物 |
| Minimal 运行文件 | 写入 | 更新锁定产物 |
| Style Settings 程序文件 | 写入 | 更新锁定产物 |
| ziminOS CSS 片段 | 写入并启用 | 更新实名自有片段 |
| Style Settings `data.json` | 写入默认配色 | 已存在则绝不覆盖 |
| `appearance.json` | 写入默认主题/片段 | 合并必要键，保留用户已选的其他主题 |
| `community-plugins.json` | 写入两个系统组件 | 只追加缺失 ID，不删用户插件 |
