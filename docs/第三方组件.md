## CSS 片段包

十一个片段来自 [guangtou.me](https://guangtou.me)「光头obsidian教程」的公开分享库（1.9 版本），随 ziminOS 一起交付；每个文件保留原始的来源/作者/功能头注释。加上 ziminOS 自有的 `ziminos-quote-semantic-colors`，成品库共十二个片段。

| 片段 | 默认 | 落地时的处理 |
| --- | --- | --- |
| `【PDF】列表参考线` | 启用 | 原样 |
| `【文件】二级文件夹前缀LOGO` | 启用 | 原样 |
| `【文件】彩虹文件夹（引导线版）` | 启用 | 原样 |
| `【文件】文件图标前缀` | 启用 | **图标区重写**：原片段按 `0_InBox`/`1_Projects` 等目录名匹配，在 ziminOS 的 `00-inbox`…`90-system` 骨架里一条都命中不了，等于交付一个死文件。改为按七个根目录精确匹配 `[data-path="…"]`，避免子目录同名路径被后缀选择器误伤 |
| `【笔记属性】自动伸缩` | 启用 | **扩展名规范为小写**：原文件名是 `.CSS`，Obsidian 的片段加载器按小写 `.css` 筛选，大写的它根本看不见——既不加载也不报错。内容一字未改 |
| `【编辑】当前行高亮（阴影）` | 启用 | 原样 |
| `【编辑-图片】居中显示` | 启用 | 原样 |
| `【编辑-代码块】增加行号` | 启用 | 原样 |
| `【编辑-Baes】隐藏新建按钮` | 启用 | 原样 |
| `【编辑-代码块】水平滑轮` | 关闭 | **选择器收窄**：原片段写的是 `.cm-content .cm-line`，而 `.cm-line` 是编辑器里的**每一行**（正文段落也是），启用后整篇笔记的正文都不再换行。改为只作用于 `.HyperMD-codeblock`；滚动条颜色由写死的 `#888/#555` 换成 Obsidian 语义变量 |
| `【编辑-水平线】中间图标` | 关闭 | 原样 |
| `ziminos-quote-semantic-colors` | 启用 | ziminOS 自有 |

默认启用清单写在 `vault/.obsidian/appearance.json` 的 `enabledCssSnippets`。两个默认关闭的片段照常交付，用户在右下角外观开关里一点即开——「交付」与「启用」是两件事，前者归安装契约，后者归用户。

`【文件】文件图标前缀` 的七行选择器绑定的是默认目录名。学员若在设置页把目录改了名，这个片段会静默失效，照着新名字改那七行即可；这是 CSS 的固有限制，不是缺陷。

## 升级所有权边界

| 资产 | 全新安装 | 升级 |
| --- | --- | --- |
| ziminOS `main.js` / `manifest.json` | 写入 | 更新锁定产物 |
| Dataview 运行文件与许可证 | 写入并启用 | 更新锁定产物，不改用户设置 |
| Minimal 运行文件 | 写入 | 更新锁定产物 |
| Style Settings 程序文件 | 写入 | 更新锁定产物 |
| ziminOS CSS 片段（十二个实名文件） | 全部写入，十个登记为启用 | 覆盖这十二个实名文件；用户自己放进 `snippets/` 的其他片段一个都不动 |
| Style Settings `data.json` | 写入默认配色 | 已存在则绝不覆盖 |
| `appearance.json` | 写入默认主题与十个启用片段 | 合并必要键，保留用户已选的其他主题；`enabledCssSnippets` **只为本次新增的片段追加**，此前已交付过的片段一律不动——用户在外观开关里关掉的东西，升级不得替他重新打开 |
| `community-plugins.json` | 写入三个系统插件 | 只追加缺失 ID，不删用户插件 |
